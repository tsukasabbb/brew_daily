01 🌿 ホップ ⭐⭐⭐⭐

「キリン ホームタップ」会員20人が遠野でホップ収穫から商品開発まで体験　遠野産ホップ100%のクラフトビールをGOOD HOPSが11月上旬に数量限定発売

Cascade・IBUKI・NoWindの3品種を比較し、5つの要素でレシピを検討　売上の一部は遠野の持続可能なホップ栽培の支援に

PR TIMES / キリンビール 日本(岩手県遠野市) 発表日: 2026年10月26日

キリンビールは2026年10月26日、会員制の生ビールサービス「キリン ホームタップ」の会員限定企画として、岩手県遠野市で「遠野ホップ“つくり手”体験イベント」を開催したと発表した。イベントは8月8日に行われ、会員20人が参加。2025年5月に遠野市で開業した醸造所「GOOD HOPS」の醸造工程の見学、ホップ畑での収穫体験、加工工場の見学に加え、ワークショップでオリジナルのクラフトビールの開発に取り組んだ。

ワークショップでは、遠野で栽培されるCascade、IBUKI、NoWindの3品種を比べ、フレッシュホップやルプリンパウダーなど加工方法による香りの違いも体験した。参加者はGOOD HOPSの試験醸造ビールを「香り」「苦味」「ボディ」「酸味」「甘味」の5つの要素で評価し、レシピを検討した。コンセプトは「遠野産ホップのみを使用すること」。完成したビールはGOOD HOPSが製造・販売し、2026年11月上旬から数量限定で、360ml缶をオンラインサイトと直営のタップルームで、樽を直営店と一部の飲食店で提供する予定だ。商品名と価格は発表文に記載がない。売上収益の一部は、遠野の持続可能なホップ栽培の支援に充てる。

GOOD HOPSの醸造責任者で「ホップ博士」として知られる村上敦司氏は「遠野産ホップ100%だからこそ生まれる新しい味わいやアイデアに期待しています」とコメント。キリンビールによると今回が4回目のイベントで、缶ビールの一般発売にも挑戦するという。遠野市とキリンビールのホップ契約栽培は1963年に始まり今年で63年目、地域活性化を目指す「TK(遠野×キリン)プロジェクト」は20年目を迎えた。

編集部の考察

飲み手をホップ畑に招き、品種比較からレシピづくりまで一緒に行う。収穫の季節を「体験」として売る取り組みが、4回目にして缶の一般発売まで届いた。IBUKIやNoWindといった国産品種を、カスケードと並べて飲み比べさせる構成もうまい。産地の物語を消費者が自分の言葉で語れるようになれば、それ自体が国産ホップの最良の宣伝になる。同じ岩手の醸造所として、県内のホップ産地と飲み手をつなぐ企画は、規模を問わずまねできるはずだ。

02 🌾 麦芽 ⭐⭐⭐⭐

英国の大麦作付け、2026年は12%減の約93万ha　スコットランドは1960年以来の低水準、干ばつで単収も17%落ち込む

製麦用プレミアムは飼料用比でトン当たり5〜15ポンドまで縮小　ウイスキー蒸留所の在庫調整で麦芽需要も減少

CMB News(Commodity Board) 英国 発表日: 2026年10月20日

穀物市況サイトのCMBニュースは2026年10月20日、英国の大麦市場の現状をまとめた。英農業園芸開発公社(AHDB)の調査データによると、2026年の英国の大麦作付面積は前年比12%減の約93万ヘクタールで、過去5年平均を約17%下回った。スコットランドは13%減の約25万8000ヘクタールと、1960年以来の低い水準となった。夏の厳しい干ばつ、特にイングランド東部の乾燥で、単収も最近の平年を約17%下回っているという。

製麦規格を満たす大麦の約8割を供給する春播き大麦が大きな打撃を受けた。それにもかかわらず、飼料用大麦に対する製麦用のプレミアムはトン当たり5〜15ポンド程度に縮んでおり、一部の地域では製麦用のロットが飼料用の価格を下回って取引されているとも伝えられる。背景には、ウイスキーの蒸留所が積み上がった原酒在庫を減らすため麦芽の使用を絞っていることがあり、記事は麦芽需要が30万トン減ると見積もっている(この数字の出典は示されていない)。一方、スコッチウイスキーの2026年上半期の輸出は数量で5.8%増、金額で2.2%増の25億ポンドだった。

飼料用大麦の相場は、10月中旬時点で黒海積みFOBがトン当たり190ドル台後半とほぼ横ばいで推移している。

編集部の考察

作付けも単収も大きく減ったのに、製麦用のプレミアムはむしろ縮んでいる。ビール向けではなく、ウイスキー向けの需要が落ちたことが価格を抑えている構図だ。カナダや米国では製麦用大麦が不足して値上がりが懸念される一方、英国産は需要減で割安感が出ている。産地によって逆の動きをしている今は、英国産のペールエールモルトなどを使うブルワリーにとって、来年分の調達条件を見直す好機かもしれない。

03 🌾 麦芽 ⭐⭐⭐

チェコの大麦作付け、10年で約4万ヘクタール減　製麦所は「たんぱく質過多」を懸念、ホップも干ばつで記録的な低アルファ酸に

チェコ農業会議所によると今年の作付面積は約28万8000ヘクタール　業界団体は「当面の原料不足はない」も長期的な先行きには警戒感

Expats.cz(チェコ・ラジオほか) チェコ 発表日: 2026年10月20日

チェコの英字ニュースサイトExpats.czは2026年10月20日、チェコのビール用大麦とホップが今年の厳しい気候の影響を受けていると報じた。プルゼニの製麦所の責任者ミハル・シュネベルゲル氏によると、今年収穫された大麦はブルワリーが望むよりたんぱく質含量が高く、発酵に使えるでんぷんが相対的に少なくなっているという。チェコ農業会議所のデータでは、今年の大麦の作付面積は約28万8000ヘクタールで、10年前より約4万ヘクタール少ない。

ホップも干ばつの打撃を受けた。Hops Connectの10月のリポートによると、ピルスナーに欠かせないザーツ(ジャテツ)種の収量は長期平均を約23%下回った。チェコホップ生産者協会は今年の収穫量を約5300トンと見込み、長期平均より20〜25%少ないとしている。同協会のイジー・スメタナ会長はチェコ・ラジオに対し、アルファ酸で測った品質は「記録上最悪の部類」だと語った。

醸造・製麦研究所のトマーシュ・ブラーニク所長は、ブルワリーには原料の品質の変動に合わせて生産を調整する技術があると述べ、チェコビール・麦芽協会のトマーシュ・スルネチコ事務局長も、醸造原料がすぐに不足する状況ではないとした。ただ両者とも、記録的な猛暑が今後も続けば長期的な見通しは楽観できないとしている。

編集部の考察

たんぱく質が高いと発酵できるでんぷんが減り、同じ量の大麦から得られる麦汁のエキス分が下がる。製麦所にとっては歩留まりの問題であり、最終的には麦芽の値付けにも跳ねやすい。10年で4万ヘクタールという作付けの目減りは、一時の不作ではなく構造的な縮小を示している。欧州産モルトを輸入に頼る部分がある日本のクラフト業界にとっても、産地ごとの作柄情報は仕込み配合を考えるうえで無視できない材料になってきた。

04 🌾 麦芽 ⭐⭐⭐

米コロラドの農場製麦所ルートシュート・モルティング、GABF新設「クラフトモルト部門」金賞のマイルドエールに麦芽を供給　ほかの顧客も多数メダル

132銘柄が競った部門で、ドスタル・アリーの「ジェイコブ・マック・マイルドエール」が金賞　ベースはイングリッシュペール

Brewbound(プレスリリース) / Root Shoot Malting 米国 発表日: 2026年10月25日

米コロラド州ラブランドのオランダー家の農場にある製麦所ルートシュート・モルティングは2026年10月25日、2026年のグレート・アメリカン・ビア・フェスティバル(GABF)で、同社の麦芽を使ったビールが多くのメダルを獲得したと発表した。同社は大麦、小麦、ライ麦、トウモロコシから麦芽をつくるクラフト製麦所。

132銘柄が出品された「クラフトモルトビール」部門では、コロラド州セントラルシティのドスタル・アリー・ブリューパブ&カジノの「ジェイコブ・マック・マイルドエール」が金賞を受賞した。ベースモルトに同社の「イングリッシュペール」、特殊麦芽に「バック・ネイキッド・チョコレート」を使っている。ドスタル・アリーは2021年から同社の麦芽を使ってきた。ほかにも、ロス・ドス・ポトリジョス・セルベセリアが「アメリカン・フルーツビール」部門で、ベント・バーレイ・ブルーイングが「ポーター・スタウト」部門で金賞を受賞。いずれもコロラドの醸造所で、前者はピルスナー、ライトミュンヘン、モルテッドコーン、後者はイングリッシュペールを使った。

同社は麦芽の品質を競う「モルトカップ」で、8年前の創設以来毎年メダルを獲得し、計18個を受賞しているという。創業者で農場主のトッド・オランダー氏は「これらの受賞は、すばらしいビールがすばらしい原料から始まることの証しだ」と述べた。

編集部の考察

本誌でも既報のとおり、今年のGABFでは「クラフトモルト部門」が初めて設けられた。その金賞が、ホップではなく麦芽の味を主役にするマイルドエールだったことは象徴的だ。農場で育てた穀物をその場で麦芽にする製麦所が、地元の醸造所の受賞を支えている。麦芽の産地や製麦所の名前を前面に出す流れは、国産の大麦や麦芽に取り組む日本の醸造所にとっても追い風になる。

05 🌽 副原料 ⭐⭐⭐

スプリングバレーブルワリー「日本のゆずエール」を10月27日全国発売　日本産ゆずピール100%使用、全国27ブルワリーとの共創企画「PLAY CRAFT BEER ACTIONS」が始動

初年度テーマは「日本らしいおいしさ」　東北からはいわて蔵ビールとGOOD HOPSが参加、350ml缶は希望小売価格236円(税抜)

キリンホールディングス ニュースリリース 日本 発表日: 2026年10月22日

キリンビールは2026年10月22日、クラフトビールブランド「SPRING VALLEY BREWERY」が全国27のクラフトブルワリーと取り組む共創プロジェクト「PLAY CRAFT BEER ACTIONS」を10月から始めたと発表した。毎年共通のテーマを決め、参加ブルワリーがそれぞれの視点で商品開発や施策に取り組む。初年度のテーマは「日本らしいおいしさ」。参加ブルワリーには、北海道の網走ビール、関東の木内酒造やYOKOHAMA BEER、関信越のヤッホーブルーイング、近畿の長濱浪漫ビールや平和酒造、九州の宮崎ひでじビールなどが名を連ね、東北からはいわて蔵ビールとGOOD HOPSが参加する。

第1弾として、SPRING VALLEY BREWERYは「日本のゆずエール」を10月27日から全国で数量限定発売する。日本産のゆずピールを100%使い、小麦麦芽を一部使用。ゆずの爽やかで奥行きのある香りと、すっきりした飲み口が特徴という。アルコール分は5%で、350ml缶の希望小売価格は236円(税抜)。15L樽は同日から直営店のスプリングバレーブルワリー東京・京都で提供し、家庭用サーバー「Tap Marché」向けの3Lペットボトルも10月26日から受注を始めた。缶は滋賀工場、樽とペットボトルは横浜工場で製造する予定だ。

編集部の考察

昨日の号で紹介した長濱麹エールと同じ企画の、主催者側の一本だ。麹、ゆずと、「日本らしさ」を副原料で表現する例が続いている。大手が全国の小規模ブルワリーを束ねて共通テーマで発信すれば、クラフトビール全体の入り口を広げる効果は大きい。一方で、ゆずや米、麹といった定番の和素材は、参加各社の個性が似通いやすい。地元にしかない素材をどう見つけるかが、参加ブルワリーの腕の見せどころになる。

06 🌽 副原料 ⭐⭐⭐

淡路ビール、地元・淡路島産の新米を麦汁にブレンドした「新米仕込みピルスナー」を10月27日から島内限定で発売

アルコール度数3.5%の軽やかな季節限定品　330ml瓶・600円(税込)、淡路ハイウェイオアシスなどで販売

PR TIMES / ユーアールエー 日本(兵庫県淡路島) 発表日: 2026年10月22日

淡路ハイウェイオアシスを運営し、「AWAJI BEER(淡路ビール)」を醸造するユーアールエーは2026年10月22日、地元・淡路島産の新米を使った季節限定のクラフトビール「新米仕込みピルスナー」を、10月27日から売り切れまで販売すると発表した。淡路島産の新米を麦汁にブレンドして仕込んだピルスナーで、アルコール度数は3.5%。

容量は330ml瓶で、希望小売価格は600円(税込)。販売は淡路島内に限り、淡路ハイウェイオアシス、waSTEP AWAJISHIMA、同社の直営店、島内の販売店で扱う。発表文には、使った米の品種や配合比率の記載はない。

編集部の考察

米は日本のビールでは定番の副原料だが、「新米」と季節を打ち出すと、秋の限定品として一気に意味を持つ。度数3.5%と低めに設計し、軽く飲めるピルスナーに仕上げたのも、観光地の土産として理にかなっている。新米の季節は全国共通で、どの産地でも同じ発想は使える。岩手でも、地元産米の新米を使った季節の一本は検討に値するだろう。

07 🌿 ホップ ⭐⭐

サッポロ「黒ラベル 東北ホップ100%」を11月4日に東北エリア限定発売　今年収穫の東北産ホップを100%使用、副原料に宮城県七ヶ宿町産の米

育種ホップ「リトルスター」の爽やかな香りを引き出す　東北で親しまれて今年18年目の限定品

日本食糧新聞 / サッポロビール 日本(東北) 発表日: 2026年10月11日

日本食糧新聞の2026年10月11日付の報道によると、サッポロビールは「サッポロ生ビール黒ラベル ＜東北ホップ100％＞」を11月4日に発売する。東北地区で今年収穫されたホップを100%使い、副原料には宮城県七ヶ宿町産の米を使用。育種されたホップ「リトルスター」の爽やかな香りを引き出したという。アルコール分は5%で、価格はオープン価格。

この時季に東北エリアだけで販売される特別な黒ラベルで、2009年の発売以来、東北の消費者に親しまれ、今年で18年目を迎える。

編集部の考察

キリンの遠野、サッポロの東北と、大手2社がそろって東北産ホップを看板にした限定品を秋に出す。東北のホップ産地が、大手にとっても欠かせない物語の源になっていることがわかる。18年続く定番になったのは、地域限定という売り方がきちんと根付いた証しだ。地元の醸造所としては、大手の限定品が店頭に並ぶこの時期こそ、県産ホップのビールを並べて飲み比べてもらう好機と捉えたい。
